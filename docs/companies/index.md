# 按公司

每家公司一页：先看风格，再按表格逐条准备。表格里的每道题都指向知识库里的条目；手撕题指向算法库。

| 公司 | 风格（根据近两年面经） |
|---|---|
| [字节跳动](./bytedance) | 算法最重，几乎每轮都手撕；八股以 Redis、MySQL 为主；AI 和 Agent 问得多；部分团队用 Go |
| [腾讯](./tencent) | 计算机基础最深（操作系统、网络、epoll、TIME_WAIT）；后台岗常用 C++ / Go；手撕偏实现题 |
| [美团](./meituan) | 场景题最多（幂等、MQ、分库分表、限流）；Java 栈；链表手撕多 |
| [阿里](./alibaba) | 项目深挖 + Java 并发、JVM 深度；秒杀、分库分表类场景；Agent 设计 |
