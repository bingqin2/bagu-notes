# 八股知识库

按模块整理 Java 后端八股：每个知识点写成「一句话答案 → 1–2 分钟展开 → 图解 → 追问链 → 我的项目里」五段。再按公司把近两年的真题指向对应的条目，准备哪家就看哪家的列表。

## 从这里开始

1. **先看[近两年考什么](/trends)**：知道该把时间花在哪里。
2. **按模块学**：每个模块的总览页有知识地图和按频率排好的条目表，从 ★★★ 开始。
3. **按公司查漏**：投递前打开[公司页面](/companies/)，把表格里每道题对应的条目过一遍。

## 进度

13 个模块、93 个条目的前四段（一句话答案、展开、图解、追问链）都已写完。每条最后的「我的项目里」留了一个问题，要结合自己的项目回答，写完才算真正掌握。

## 复习方法

- **闭卷讲**：每周从目录里随机挑 5 条，只看标题讲 1–2 分钟，讲不顺的标记下来。
- **补面经**：读到知识库里没有的题，在对应模块新建条目，运行 `python3 tools/gen_index.py` 更新总览。
- **连到项目**：每条都写「我的项目里」，八股和项目深挖就能打通。
